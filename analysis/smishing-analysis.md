# Smishing Analysis Report

## Resumen
SMS fraudulento suplantando DIAN dirigido a contribuyentes colombianos.

## IOCs Detectados
1. *Número*: +57 301 555 8821
2. *URL maliciosa*: dian-gov.co.verificar.xyz
3. *Técnica*: T1566.004 Smishing

## Indicadores de Phishing
- Urgencia: "24 horas para evitar sanción"
- Dominio falso: dian-gov.co vs dian.gov.co real
- Solicitud de datos personales + bancarios

## Recomendación
DIAN nunca pide datos por SMS. Verificar solo en dian.gov.co
